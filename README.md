# Data Redundancy Removal System

## Objective

To identify and eliminate duplicate records before storing data in the database.

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* Bootstrap

## Features

* User data entry form
* Database storage
* Duplicate email detection
* Prevention of redundant records
* User feedback messages

## Working

The system accepts user details such as Name, Email, and Phone Number. Before inserting a record into the database, it checks whether the email already exists. If a duplicate record is found, the system prevents insertion and displays a warning message. Otherwise, the record is successfully stored in the database.

## Outcome

The project successfully removes redundant data and ensures only unique records are stored.
